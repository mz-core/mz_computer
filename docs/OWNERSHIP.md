# Ownership

| Domínio | Owner |
|---|---|
| Player/citizen identity | `mz_core` |
| Digital account do MZ OS | `mz_computer` |
| Password hash | `mz_computer` |
| Computer session | `mz_computer` |
| Device / terminal lease | `mz_computer` |
| OS settings / notes / documents | `mz_computer` |
| App/Site registry | `mz_computer` |
| Inventário e posse do item | owner canônico de inventory (`mz_core` no baseline atual) |
| Banco / ledger | resource bancário/economia owner |
| Jobs/orgs | respectivos owners |
| Houses / vehicles | respectivos owners |

Regra: um app dentro do computador não transfere ownership do domínio para `mz_computer`.
